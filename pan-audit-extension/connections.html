Certificados autofirmados: antes de conectar, abre https://<host> en una pestana normal una vez y acepta la advertencia del certificado — si no, la conexion falla con error de red aunque las credenciales sean correctas.

La contrasena se usa una sola vez para pedir la API key (type=keygen) y no se guarda; solo se almacena la API key resultante. Los modulos del dashboard reutilizan esa key: no vuelves a escribir credenciales.
